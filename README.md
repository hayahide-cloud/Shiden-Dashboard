# Shiden-Dashboard
資産ダッシュボードの公開ホスティング（実データは非公開リポジトリから読込）

- `index.html` — ダッシュボード本体（表示専用）
- `password-manager/` — Shiden Password Manager（紫電パスワードマネージャー・仮）の暫定設置先。独立リポジトリへ移設予定（Shiden Assets と同じ経緯）。詳細は `password-manager/README.md`
- `asset-input/` — 旧 Shiden Assets の案内ページ（本体は `Shiden-Assets` リポジトリへ移転済）
